# personal-portfolio-fullstack

Portfolio personal profesional de Ignacio Fayos Gómez, orientado a perfil backend y con una base full stack separada en frontend y backend.

## Stack previsto

- Frontend: Next.js con TypeScript
- Backend: Laravel API
- Base de datos: PostgreSQL
- Autenticación admin (más adelante): Laravel Sanctum
- Despliegue previsto:
  - Frontend en Vercel
  - Backend en VPS o servicio compatible con Laravel
